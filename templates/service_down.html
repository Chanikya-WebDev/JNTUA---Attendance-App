Important Notice

The JNTUA Attendance Android App is now the recommended way to access attendance services. Because of recent security updates on the attendance portal, downloading the application provides the most reliable and seamless experience.

How to download and install

Follow these six quick steps to get started.

1

Open the release page

Click the “Download App” button. This will redirect you to our GitHub Releases page.

2

Find the APK

On the GitHub Release page, locate the “Assets” section and tap the APK file to begin downloading.

3

Wait for the download

Once complete, the APK will appear in your Downloads folder.

4

Open the APK

Open the downloaded APK. If Android asks which app to use, choose “Package Installer”.

5

Install the app

Tap “Install” and wait for the installation to complete.

6

Open and login

Tap “Open”, then login using your JNTUA credentials.
